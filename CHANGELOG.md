# Changelog

## 1.2.0

First public-ready Oh My Departure release, derived from the local R Departures
Linux / Omarchy port.

- English-first documentation, Codex UI and default session board.
- New `ohmydeparture` executable and `edwardkim.ohmydeparture` Omarchy identity.
- Read-only session monitoring, agent trees, search, filters and turn/tool details.
- Original split-flap board with deterministic project colours.
- Configurable 3-second replay and 0.65-second flip, hinge pause and fold shading.
- Monitor-centred details/settings with app-scoped Hyprland placement.
- Existing-window view switching through an app-owned local socket.
- Legacy managed-plugin migration with preserved placement/settings and rollback.
- Inherited airport and railway boards, icon, fonts and original credits.
- Source tests, isolated installer checks, Ubuntu CI and tag-triggered release workflow.
