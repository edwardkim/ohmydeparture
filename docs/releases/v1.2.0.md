First public release of **Oh My Departure**, an English-first Codex session and
agent board for Linux / Omarchy, derived from rainygirl's R Departures.

- Split-flap project plaques, agent trees, session search and turn/tool history.
- Read-only Codex monitoring with local JSONL fallback.
- Adjustable replay (default 3 seconds) and visible flips (default 0.65 seconds).
- Screen-centred details and settings; original airport and railway boards.
- Omarchy bar widget, application launcher and icon.
- Migration from the managed `rainygirl.rdepartures` local plugin, preserving bar
  position and settings, with backups and rollback.

Extract the compatible `ohmydeparture-omarchy-*.tar.gz` bundle and run
`python3 install.py` as your regular desktop user. Requires Omarchy's bar-widget
API, Python 3 and system Qt 6; see the bundled README and BUILD-INFO.json.
Close any previous R Departures window before launching the new app.

HISTORY means runtime unknown; a completed turn does not mean project completion.
Timetables are generated examples. The included demonstration uses synthetic data.

MIT source, original R Departures attribution retained, GUST font license included.
